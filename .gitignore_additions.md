# Additional .gitignore Patterns for Cline

Patterns recommended for VS Code extension development:

```gitignore
# VS Code extension packaging output
*.vsix

# TypeScript incremental compilation
*.tsbuildinfo

# esbuild output
out/
dist/

# macOS
.DS_Store

# Windows
Thumbs.db

# JetBrains IDEs
.idea/
*.iml

# Local test secrets
.env.local
test-secrets.json

# Webview development
webview-ui/node_modules/
webview-ui/build/
```
